Cisco WLC Wireless Setup Guide

Cisco Wireless LAN Controller, Access Point, VLAN, SSID, and RADIUS Configuration

Tools Used

  1. Cisco WLC 4504
  2. Cisco Aironet AIR-CAP2602I-A-K9 Access Point
  3. Distribution Switch: Cisco Nexus 9372PX-E Switch
  4. Access Switch: Cisco Catalyst 2960
  5. DHCP Server: ubuntu server vm on vmware
  6. Active Directory (AD), DNS, and NPS/RADIUS Server on physical Cisco UCS C220 M4

Requirements

  1. DHCP Server: A DHCP server is required for the wireless network. The DHCP server must be reachable from VLAN 10 and VLAN 20, with the appropriate DHCP scopes configured.
  2. Active Directory, DNS, and NPS/RADIUS: Active Directory, DNS, and Network Policy Server (NPS) are required for RADIUS authentication and centralized wireless user authentication.
  3. Distribution and Access Switches: The WLC should be connected to the network through a trunk port. The Access Point should be connected to an appropriate access port on the access switch.
  4. VLANs: The required VLANs must be created and available across the network. In this example, VLAN 10 is used for management/internal traffic and VLAN 20 is used for the Guest wireless network.
  5. Network Connectivity: Routing, gateways, DHCP, DNS, and RADIUS connectivity must be working before testing the wireless network.

WLC Setup

  1. Assign an IP address to the WLC management interface. Configure the management IP address, subnet mask, default gateway, and other required network settings.
  2. Connect the WLC to the switch. Connect the WLC to the appropriate switch trunk port and make sure the required VLANs are allowed on the trunk.
  3. Access the WLC Web GUI. After confirming network connectivity, access the WLC management interface using a web browser.
  4. Connect the Access Point. Connect the AP to the access switch. The AP should obtain an IP address through DHCP and attempt to discover and join the WLC.
  5. Verify the AP connection. Log in to the WLC and verify that the AP has successfully joined.
  6. Troubleshoot if the AP does not join. Check DHCP, VLAN configuration, IP connectivity, AP discovery, compatibility, and WLC settings. Review the AP join status and WLC logs for additional information.
  7. Configure AP policies. If not joined, check/test/change the AP policies
  8. Confirm the AP is listed. A successfully joined AP should appear in the WLC's AP management or wireless AP list.

Configure the Wireless Interface

  1. Log in to the WLC Web GUI.
  2. Navigate to: Controller > Interfaces
  3. Click New to create a new dynamic interface.
  4. Enter the interface information. Example:
    • Interface Name: Guest
    • VLAN ID: 20
    • IP Address: Appropriate VLAN 20 address
    • Subnet Mask: VLAN 20 subnet mask
    • Default Gateway: VLAN 20 gateway
  5. Save the configuration.
The WLC dynamic interface maps the wireless SSID to the appropriate VLAN. In this example, the Guest SSID is mapped to VLAN 20.

Configure the Wi-Fi SSID

  1. Navigate to: WLANs
  2. Create a new WLAN.
  3. Enter the WLAN information. Example:
    • Profile Name: Guest
    • SSID: Guest
  4. Enable the WLAN.
  5. Select the dynamic interface created earlier. For example, select the Guest interface associated with VLAN 20.
  6. Save the WLAN configuration.

Configure Wi-Fi Security and RADIUS

  1. Open the security settings for the WLAN.
  2. Under Layer 2 security, select the appropriate WPA/WPA2 security option.
  3. Enable the required encryption method, such as AES, and select the appropriate WPA2 policy.
  4. Configure RADIUS/AAA authentication for centralized authentication.
  5. Add the RADIUS server under: Security > AAA > RADIUS > Authentication
  6. Enter the RADIUS server IP address and shared secret.
  7. Return to the WLAN security settings and select the configured RADIUS authentication server under the AAA server settings.
  8. Save and apply the configuration.
Important: The RADIUS shared secret configured on the WLC must match the shared secret configured for the WLC as a RADIUS client on the NPS server.

Testing and Verification

  1. Connect a wireless client to the new SSID.
  2. Verify that the client successfully authenticates.
  3. Verify that the client receives an IP address from the correct DHCP scope.
  4. Confirm that the client is placed in the correct VLAN.
  5. Test connectivity to the required network resources.
  6. Verify the connected client in the WLC wireless client list.
  7. If authentication fails, check the NPS logs, RADIUS configuration, shared secret, user/group permissions, and WLAN security settings.
