03 / Validation Test

Nmap Scan Detection

The first validation test uses an Nmap network scan to generate reconnaissance traffic. The objective is to confirm that the monitoring stack can observe the scan and surface the resulting security event in the SIEM.

RECONNAISSANCE TEST

🔎 Nmap Network Scan

An Nmap scan generates multiple connection attempts against ports on the target system. This creates a recognizable network pattern that can be inspected by Suricata.

How the detection works

  • Nmap generates reconnaissance traffic.
  • Network traffic is observed by Suricata.
  • Suricata evaluates the traffic against configured IDS rules.
  • A matching event is written to the Suricata event log.
  • The Suricata event is forwarded to Splunk.
  • Splunk makes the event searchable for investigation.
Evidence: Nmap scan screenshot captured during the validation test.
04 / Validation Test

Brute-Force Attack Detection

The second validation test uses Hydra to generate repeated authentication attempts. The goal is to demonstrate how repeated login activity can be observed by the monitoring stack and identified as suspicious behavior.

BRUTE-FORCE TEST

🔐 Hydra Brute-Force Test

Hydra generates repeated authentication attempts against the selected service. The resulting traffic provides a realistic test case for validating brute-force detection and SIEM visibility.

How the detection works

  • Hydra generates repeated authentication attempts.
  • The network traffic is observed by the IDS sensor.
  • Suricata evaluates the traffic against configured rules.
  • Matching security events are recorded.
  • Suricata events are forwarded to Splunk.
  • Splunk provides centralized visibility for investigation.
Evidence: Hydra brute-force screenshot captured during testing.
05 / SIEM Visibility

Splunk Security Monitoring

Splunk acts as the central analysis platform. Once logs and Suricata security events are ingested, analysts can search the data, review events, identify suspicious activity, and correlate activity across multiple sources.

📊 Centralized Security Visibility

The Splunk interface provides visibility into incoming network and security telemetry. The SIEM can be used to validate that the events generated during the Nmap and brute-force tests are reaching the monitoring platform.

🌐 Network Event Monitoring
