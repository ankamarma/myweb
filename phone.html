VoIP Infrastructure Configuration Guide

Tools & Infrastructure Used

  • 🛠️ Catalyst 2960 Switch
  • 💻 VMware 7.0 Hypervisor
  • 📞 Cisco CUCM 14.0.1.11900-132
  • 🍃 FreePBX 17.0.32 Server

FreePBX Setup Procedure

  1. Install FreePBX Server: Spin up and install the FreePBX 17.0.32 software package on your virtual machine within VMware 7.0.
  2. Multiplatform Firmware: Verify the endpoint phone is configured with multiplatform firmware capabilities.
  3. Create Extension: Navigate to the main menu page path Connectivity > Extensions to construct a new line extension.
  4. Network Assignment: Input the required network topology settings directly onto the device panel layout parameters.
  5. Access Phone GUI: Open a local web browser session and navigate to the IP address of the active phone node.
  6. SIP Mapping Details: Log inside the device profile console, click Advanced > Voice > Extension, and populate the appropriate Port number, Extension Secret string, and the target SIP/FreePBX IP destination.
  7. Verify Active Registry: Review the active session statuses via the management dashboard under Reports > Asterisk Info to confirm successful binding.

Cisco CUCM Setup Procedure

  1. Install CUCM node: Run the setup installer for the Cisco CUCM 14.0.1.11900-132 target image deployment inside VMware 7.0.
  2. TFTP Network Settings: Build out your local telephone system routing network and provision the designated CUCM IP value to point to your target TFTP destination.
  3. Activate Local TFTP Daemon: Because the internal TFTP engine is deactivated by default, browse to the Cisco Unified Serviceability drop-down menu, go to Tools > Service Activation, locate the primary Feature Services group, and click start.
  4. Provision Phone Hardware: Manually append the new target terminal inside the node database (e.g., Cisco 8864 appliance) alongside its matching hardware MAC Address string.
  5. Bind DN Extension: Set up and define the specific telephone extensions parameters directly underneath the Directory Number (DN) menu page.
  6. DNS-less Hostname Override: If performing your deployment without an active functional DNS cluster environment, access the Enterprise Parameters configuration layout view and substitute the alphanumeric server descriptors with the clear IPv4 address of the running CUCM core node.
