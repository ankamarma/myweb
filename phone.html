  • 💻 VMware 7.0 Hypervisor
  • 📞 Cisco CUCM 14.0.1.11900-132
  • 🍃 FreePBX 17.0.32 Server
  • ☎️ Cisco Phone 8864

FreePBX Setup Procedure

  1. install freepbx server
  2. Phone shoul be multiplatform
  3. Make extension by going to Connectivity>extension
  4. put network info on phone.
  5. Access the webgui of the phone
  6. Put the port number, secret from the extension during extension creation SIP/FREEPBX IP on phone webgui on advanced>voice>extension
  7. Check whether it is registered under report>asterick info

Cisco CUCM Setup Procedure

  1. install cucm
  2. set up phone network and put cucm ip on TFTP
  3. By default, TFTP is not deactivated activate it by visiting to cisco servicebility and under tools select service activation and after that under feature service start it.
  4. Add and select phone eg 8864 and mac address
  5. add extension number under DN
  6. if without dns, go to enterprise parameter and replace the ip of cucm that has alpbaet name and picture add at the end. make picture zoomable when click on them
