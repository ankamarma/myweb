VoIP Infrastructure Configuration Guide

Tools & Infrastructure Used

  • 🛠️ Catalyst 2960 Switch
  • 💻 VMware 7.0 Hypervisor
  • 📞 Cisco CUCM 14.0.1.11900-132
  • 🍃 FreePBX 17.0.32 Server
  • ☎️ Cisco Phone 8864

FreePBX Setup Procedure

  1. Install the FreePBX server.
  2. Ensure the phone is using multiplatform firmware.
  3. Create an extension by navigating to Connectivity > Extensions.
  4. Configure the network settings on the phone.
  5. Access the web GUI of the phone.
  6. On the phone web GUI, navigate to Advanced > Voice > Extension. Enter the port number, the secret generated during extension creation, and the SIP/FreePBX IP address.
  7. Verify the registration status under Reports > Asterisk Info.

Cisco CUCM Setup Procedure

  1. Install CUCM.
  2. Set up the phone network and assign the CUCM IP address as the TFTP server.
  3. By default, TFTP service is deactivated. Activate it by navigating to Cisco Unified Serviceability. Under Tools, select Service Activation, find the feature service, and start it.
  4. Add and select the phone (e.g., Cisco 8864) and enter its MAC address.
  5. Add the extension number under Directory Number (DN).
  6. If deploying without DNS, go to Enterprise Parameters and replace the alphabetical CUCM hostnames with the actual CUCM IP address. Click the image below to view details.
