VoIP Deployment Guide

Tools Used

  • Hardware Switch: Catalyst 2960
  • Hypervisor Platform: VMware 7.0
  • PBX Server 1: FreePBX 17.0.32
  • PBX Server 2: CUCM 14.0.1.11900-132 (Single Instance Node)
  • Endpoint Device: Cisco IP Phone 8864

1. FreePBX Deployment Steps

  1. Install the FreePBX 17.0.32 server. Set up the platform environment on your VMware 7.0 hypervisor host.
  2. Ensure the phone is multiplatform. Verify that your device firmware supports standard open SIP configurations.
  3. Create a new extension profile. Navigate to Connectivity > Extensions within the FreePBX administration panel.
  4. Configure network information manually on the phone. Assign local IP, subnet, gateway, and VLAN routing settings via the Catalyst 2960 infrastructure without using DHCP.
  5. Access the phone's web GUI. Input the manually configured local IP address of your endpoint device into a secure web browser.
  6. Apply SIP credentials on the phone GUI. Navigate to Advanced > Voice > Extension. Input your port details, target FreePBX server IP, and the custom secret key created with the extension.
  7. Verify registration status. Go to Reports > Asterisk Info in FreePBX to confirm the endpoint has successfully connected.

2. Cisco Unified Communications Manager (CUCM) Deployment Steps

  1. Install the single-node CUCM 14.0.1.11900-132 server. Provision and build the standalone machine instance using your VMware 7.0 virtualization environment.
  2. Set up the voice network and manually point to TFTP. Provision network routing on the Catalyst 2960 switch and manually configure the CUCM IP address as the TFTP server address directly on the Cisco 8864 phone layout.
  3. Activate the TFTP feature service. By default, the TFTP service is deactivated. Enable it by navigating to Cisco Unified Serviceability > Tools > Service Activation, locating the feature services, and starting the Cisco TFTP service.
  4. Add the target endpoint hardware. Select your phone model hardware tier (Cisco 8864) and manually link the unit's unique physical MAC address.
  5. Assign a Directory Number (DN). Bind your target numeric extension pattern directly under the active DN structural line parameters.
  6. Configure fallback IP mapping (Non-DNS setups). Go to Enterprise Parameters and overwrite alphanumeric system hostnames with literal CUCM node IP details.
