2. System Components & Prerequisites

Infrastructure Checklist

  • FreePBX Instance (Asterisk 16+ utilizing Chan_PJSIP driver)
  • Cisco Unified Communications Manager (CUCM Cluster v11.5+)
  • Network Route Permissions for Local Subnets
  • Firewall Exceptions: UDP 5060 (SIP) & UDP 10000-20000 (RTP Media)

3. FreePBX SIP Trunk Deployment

Apply the following technical configurations to link your Asterisk engine safely to the Cisco system backend infrastructure.

3.1 Chan_PJSIP Custom Settings

[cucm-trunk]
type=endpoint
transport=transport-udp
context=from-internal
disallow=all
allow=ulaw
allow=alaw
aors=cucm-trunk
outbound_auth=cucm_auth

[cucm-trunk]
type=aor
contact=sip:192.168.10.50:5060

4. Cisco Unified CM Trunk Settings

Complete the bi-directional pairing configurations by defining your system profiles and security paths within CallManager.

  1. SIP Trunk Security Profile: Navigate to System > Security > SIP Trunk Security Profile. Create a non-secure profile listening on port 5060.
  2. Create SIP Trunk Device: Go to Device > Trunk. Add a new SIP trunk matching the explicit destination network address of your FreePBX engine.
  3. Dial Plan Route Selection: Configure explicit destination string patterns (e.g., 4XXX vs 5XXX) to cleanly steer cross-vendor endpoint calls.
