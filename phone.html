VoIP Deployment Guide

1. FreePBX Deployment Steps

  1. Install the FreePBX server. Set up the base operating system and FreePBX platform on your dedicated hardware or virtual machine.
  2. Ensure the phone is multiplatform. Verify that your hardware supports open SIP standards to communicate with FreePBX.
  3. Create a new extension. Navigate to Connectivity > Extensions in the FreePBX web interface to add a new device profile.
  4. Configure network information on the phone. Assign a valid IP address, subnet mask, and gateway directly to your physical or software phone.
  5. Access the phone's web GUI. Open a web browser and enter the IP address of the phone to access its configuration portal.
  6. Configure SIP settings on the phone. Navigate to Advanced > Voice > Extension. Enter the port number, the secret (password) generated during extension creation, and the FreePBX server IP.
  7. Verify registration status. Go to Reports > Asterisk Info in FreePBX to confirm the phone has successfully registered.

2. Cisco Unified Communications Manager (CUCM) Deployment Steps

  1. Install the CUCM server. Complete the base installation of the Cisco Unified Communications Manager cluster.
  2. Configure the network and TFTP settings. Set up the phone network parameters and ensure the CUCM IP address is provisioned as the TFTP server option (Option 150) in your DHCP scope.
  3. Activate the TFTP service. By default, the TFTP service is deactivated. Enable it by navigating to Cisco Unified Serviceability > Tools > Service Activation, locating the feature services, and starting the Cisco TFTP service.
  4. Add the physical device. Select your phone model (e.g., Cisco 8864) and enter its unique MAC address into the system.
  5. Assign a Directory Number (DN). Add the desired extension number under the DN configuration line for the device.
  6. Configure IP-based routing (Non-DNS environments). If you are operating without a DNS server, navigate to Enterprise Parameters and replace any alphanumeric hostnames with the literal IP address of your CUCM server.
