2. System Components

Deployment Requirements

  • FreePBX Server (Asterisk 16+ / Chan_PJSIP driver)
  • Cisco Unified Communications Manager (CUCM v11.5+)
  • Configured network routing with open SIP (5060/5061) and RTP (10000-20000) ports

3. Configuration Steps

  1. Configure FreePBX SIP Trunk: Create a new Chan_PJSIP trunk targeting the primary CUCM node IP address. Set the context to 'from-internal'.
  2. Configure CUCM SIP Trunk Security Profile: Navigate to System > Security > SIP Trunk Security Profile. Create a non-secure or secure profile matching your transport layer choice.
  3. Define Inbound and Outbound Dial Plans: Build patterns to seamlessly steer traffic across matching destination numbers. Route 4-digit strings respectively between architectures.
