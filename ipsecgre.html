Simple Site-to-Site IPsec over GRE

  1. Configure ISAKMP (Phase 1): Define the authentication, encryption, and hashing algorithms to establish a secure management tunnel between the routers.
  2. Configure IPsec (Phase 2): Define the transform set and security associations to encrypt the actual data traffic.
  3. Configure the Tunnel Interface: Create a virtual GRE tunnel interface, assign IP addresses, and apply the IPsec profile to encrypt the tunnel traffic.

DMVPN (Dynamic Multipoint VPN)

  1. Configure ISAKMP (Phase 1): Define the authentication and encryption parameters to establish the management tunnel between the hub and spoke routers.
  2. Configure IPsec (Phase 2): Define the transform set and IPsec profile used to protect the data payload.
  3. Configure the Tunnel Interface: Create the multipoint GRE (mGRE) tunnel interface, assign IP addresses, and link the IPsec profile.
  4. Configure the Hub Router: Enable Next Hop Resolution Protocol (NHRP) on the hub's tunnel interface, designating it as the Next Hop Server (NHS).
  5. Configure the Spoke Routers: Under the spoke tunnel interfaces, map the virtual tunnel IP to the hub's public IP address, and point NHRP to the hub router.
