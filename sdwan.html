3. Enterprise CA on vManage

In this lab, the enterprise CA is created on vManage. The CA is used to sign certificates for vManage, vBond, vSmart and the SD-WAN edge devices.

3.1 Generate the CA Private Key

openssl genrsa -out lab-root-ca.key 4096

This creates the private key: lab-root-ca.key

3.2 Generate the Root CA Certificate

openssl req -x509 -new -nodes \
  -key lab-root-ca.key \
  -sha256 \
  -days 3650 \
  -out lab-root-ca.pem \
  -subj "/C=US/ST=NC/O=test-sdwan/CN=test-sdwan-ROOT-CA"

This creates the public root certificate: lab-root-ca.pem

3.3 Add the Root CA to vManage

Copy the contents of lab-root-ca.pem and add it under the vManage Enterprise Certificate Authority settings.

4. vManage Certificate

Step 1: Generate the CSR for vManage.
Step 2: Transfer or access the CSR on vManage.
Step 3: Sign the CSR using the enterprise CA. 
openssl x509 -req \
  -in vmanage_csr \
  -CA lab-root-ca.pem \
  -CAkey lab-root-ca.key \
  -CAcreateserial \
  -out vmanage.crt \
  -days 3650 \
  -sha256
Step 4: Install the signed certificate on vManage.

5. vBond / vSmart Certificates

Step 1: Add the vBond or vSmart device and generate the CSR.
Step 2: Transfer the CSR to vManage.
Step 3: Sign the CSR on vManage. 
openssl x509 -req \
  -in /home/admin/vbond_csr \
  -CA lab-root-ca.pem \
  -CAkey lab-root-ca.key \
  -CAcreateserial \
  -out vbond.crt \
  -days 3650 \
  -sha256
Step 4: Transfer the CRT file back to vBond or vSmart.
Step 5: Install the root certificate chain. 
request root-cert-chain install /home/admin/lab-root-ca.pem
Step 6: Install the signed CRT certificate.

6. C8000V / 8000V Edge

The C8000V must be converted from autonomous mode to SD-WAN mode before onboarding it into the SD-WAN fabric.

6.1 Basic SD-WAN Configuration

config terminal

system
  host-name <unique-hostname>
  system-ip <ip-address>
  site-id <site-id>
  organization-name <org-name>
  vbond <vbond-address>

interface Tunnel0
 no shutdown
 ip unnumbered GigabitEthernet1
 tunnel source GigabitEthernet1
 tunnel mode sdwan

sdwan
 interface GigabitEthernet1
  tunnel-interface
   encapsulation ipsec
   allow-service all

6.2 Install the Root CA

copy or transfer the key .pem from vmanage to edge(using this command tclsh eg puts [open "flash:ROOT-CA.pem" w+] { [paste the certificate here] }) then the next step 

request platform software sdwan root-cert-chain install bootflash:<root-ca>.pem

6.3 Generate the CSR

request platform software sdwan csr upload bootflash:<csr-file>

6.4 Transfer the CSR to vManage

Transfer the generated CSR from the edge device to vManage.

6.5 Sign the Edge CSR

openssl x509 -req \
  -in /home/admin/edge-r1_csr \
  -CA lab-root-ca.pem \
  -CAkey lab-root-ca.key \
  -CAcreateserial \
  -out edge-r1.crt \
  -days 3650 \
  -sha256

6.6 Install the Certificate on the Edge

request platform software sdwan certificate install bootflash:edge-r1.crt

6.7 Add the Edge

request vedge add chassis-num C8K-3539796c-b995-4c41-b6a1-1d7cf7f9a9a2 serial-num 0861ACC2EE28C7D3045CB9CE465149BA72624F49
Replace the chassis number and certificate serial number with the values from your own device.

Overall steps

  • 1. Generate Root CA Keys: Log into the vManage CLI (vshell) and create the lab-root-ca.key and lab-root-ca.pem files using OpenSSL.
  • 2. Set CA Type in UI: Copy the text of lab-root-ca.pem. In the vManage Web UI, go to Administration > Settings > Controller Certificate Authorization, select Enterprise CA, paste the text, and save.
  • 3. Generate vManage CSR: In the UI (Configuration > Certificates > Controllers), click Generate CSR for vManage and copy the text.
  • 4. Sign vManage CSR: Save the text as a file on the vManage CLI and run the OpenSSL signing command to output vmanage.crt.
  • 5. Install vManage Certificate: Return to the vManage UI, click Install Certificate, and paste the contents of vmanage.crt.

Phase 2: Onboard vBond & vSmart Controllers

  • 1. Add Controllers: In the UI (Configuration > Devices), add your vSmart and vBond controllers using their IP addresses and CLI credentials.
  • 2. Generate Controller CSRs: In the UI (Configuration > Certificates > Controllers), select the vSmart and vBond entries and click Generate CSR. (vManage fetches these automatically via NETCONF).
  • 3. Sign Controller CSRs: Copy or download the CSR texts, save them to files on the vManage CLI, and sign them with your OpenSSL root keys to output vbond.crt and vsmart.crt.
  • 4. Install Controller Certificates: Return to the UI, click Install Certificate, and paste the respective .crt text for each controller. vManage will automatically push them out.

Phase 3: Prepare the WAN Edge (CSR1000v/C8000v)

  • 1. Apply Bootstrap Config: On the router CLI, configure the basic controller parameters (system-ip, site-id, org-name, vbond) and the Tunnel0 interface.

Phase 4: Sign & Install the WAN Edge Certificate

  • 1. Install Root CA on Edge: Copy lab-root-ca.pem from vManage to the router's bootflash: and run:
    request platform software sdwan root-cert-chain install bootflash:lab-root-ca.pem
  • 2. Generate Edge CSR: Run the following on the router to create a CSR file:
    request platform software sdwan csr upload bootflash:edge.csr
  • 3. Sign Edge CSR: Copy edge.csr to the vManage CLI and run the OpenSSL signing command to create edge.crt.
  • 4. Install Edge Certificate: Copy edge.crt back to the router's bootflash: and run:
    request platform software sdwan certificate install bootflash:edge.crt
  • 5. Activate the Fabric Association: Run the final onboarding command on the router to link the certificate:
    request platform software sdwan vedge_activate chassis-number <ID> token <TOKEN>
