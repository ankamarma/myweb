2. Enterprise CA on vManage

The enterprise CA is created on vManage. It is used to sign certificates for the SD-WAN devices.

Generate the CA Private Key

openssl genrsa -out lab-root-ca.key 4096

Generate the Root CA Certificate

openssl req -x509 -new -nodes \
  -key lab-root-ca.key \
  -sha256 \
  -days 3650 \
  -out lab-root-ca.pem \
  -subj "/C=US/ST=NC/O=test-sdwan/CN=test-sdwan-ROOT-CA"

This creates the root certificate: lab-root-ca.pem

Add the Root CA to vManage

Copy the contents of lab-root-ca.pem and add it under the vManage Enterprise Certificate Authority settings.

3. vManage Certificate

Step 1: Generate the vManage CSR.
Step 2: Access the CSR from vManage.
Step 3: Sign the CSR using the enterprise CA. 
openssl x509 -req \
  -in vmanage_csr \
  -CA lab-root-ca.pem \
  -CAkey lab-root-ca.key \
  -CAcreateserial \
  -out vmanage.crt \
  -days 3650 \
  -sha256
Step 4: Install the signed certificate on vManage.

4. vBond and vSmart Certificates

Step 1: Add vBond and vSmart and generate their CSRs.
Step 2: Transfer the CSRs to vManage.
Step 3: Sign the certificates using the enterprise CA. 
openssl x509 -req \
  -in /home/admin/vbond_csr \
  -CA lab-root-ca.pem \
  -CAkey lab-root-ca.key \
  -CAcreateserial \
  -out vbond.crt \
  -days 3650 \
  -sha256
Step 4: Transfer the certificate back to vBond or vSmart.
Step 5: Install the root certificate chain. 
request root-cert-chain install /home/admin/lab-root-ca.pem
Step 6: Install the signed certificate.

5. C8000V SD-WAN Edge

Convert the C8000V to SD-WAN mode before onboarding it into the SD-WAN fabric.

Basic Configuration

config terminal

system
  host-name <hostname>
  system-ip <system-ip>
  site-id <site-id>
  organization-name <organization-name>
  vbond <vbond-address>

interface Tunnel0
 no shutdown
 ip unnumbered GigabitEthernet1
 tunnel source GigabitEthernet1
 tunnel mode sdwan

sdwan
 interface GigabitEthernet1
  tunnel-interface
   encapsulation ipsec
   allow-service all

Install the Root CA

Copy the root CA certificate from vManage to the edge device. 

request platform software sdwan root-cert-chain install bootflash:<root-ca>.pem

Generate the CSR

request platform software sdwan csr upload bootflash:<csr-file>

Sign the Edge CSR

Transfer the CSR to vManage and sign it using the enterprise CA. 

openssl x509 -req \
  -in /home/admin/edge-r1_csr \
  -CA lab-root-ca.pem \
  -CAkey lab-root-ca.key \
  -CAcreateserial \
  -out edge-r1.crt \
  -days 3650 \
  -sha256

Install the Edge Certificate

request platform software sdwan certificate install bootflash:edge-r1.crt

Add the Edge

request vedge add chassis-num C8K-3539796c-b995-4c41-b6a1-1d7cf7f9a9a2 serial-num 0861ACC2EE28C7D3045CB9CE465149BA72624F49
Use the chassis number and certificate serial number from your own device.

7. Overall Steps

Phase 1: vManage

  1. Generate the root CA key and certificate on vManage.
  2. Add the root CA certificate in the vManage GUI.
  3. Generate the vManage CSR.
  4. Sign the vManage CSR.
  5. Install the vManage certificate.

Phase 2: vBond and vSmart

  1. Add vBond and vSmart in vManage.
  2. Generate their CSRs.
  3. Sign the CSRs using the root CA.
  4. Install the certificates.

Phase 3: SD-WAN Edge

  1. Configure the basic SD-WAN settings on the edge.
  2. Install the root CA certificate.
  3. Generate the edge CSR.
  4. Sign the CSR on vManage.
  5. Install the signed certificate.
  6. Activate and onboard the edge device.
