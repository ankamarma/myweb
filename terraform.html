VM Deployment Guide on VMware ESXi Using Terraform

This guide outlines the procedure for deploying Virtual Machines (VMs) onto a standalone VMware ESXi host utilizing Terraform from a Windows Subsystem for Linux (WSL) environment.

Environment & Tools

  • Hardware Platform: Cisco UCS C220 M4 Rack Server
  • Hypervisor: VMware ESXi
  • Infrastructure as Code: Terraform
  • Local Workstation OS: Windows with WSL2 (Ubuntu)
  • Source Image: Operating System OVA file (stored in the Ubuntu virtualbox-ova directory)

Step-by-Step Instructions

  1. Set up the Environment: Open and configure your WSL Ubuntu environment on Windows.
  2. Install Terraform: Download and install the appropriate Terraform binary on your WSL Ubuntu instance.
  3. Configure Secrets (terraform.tfvars): Create your credentials mapping file.
  4. Define Variables (variables.tf): Establish deployment target options.
  5. Create Main Configuration (main.tf): Standardize your target architecture code.
  6. Implement Deployment Automation (deploy.sh): Scale elements live using dynamic state tracking.
Important Automation Note: By default, declarative tools like Terraform attempt to tightly manage a fixed state file, which can result in existing VMs being destroyed or overwritten when you attempt to spin up additional independent instances. The deploy.sh script dynamically queries the existing VM count on the host, allowing you to safely scale up and provision new VMs sequentially without disrupting the existing infrastructure.

terraform {
  required_providers {
    esxi = {
      source  = "josenk/esxi"
      version = "1.10.3"
    }
  }
}

provider "esxi" {
  esxi_hostname = var.esxi_hostname
  esxi_username = var.esxi_username
  esxi_password = var.esxi_password
}

# UBUNTU FLEET
resource "esxi_guest" "ubuntu_vms" {
  count              = lower(var.os_choice) == "ubuntu" ? var.vm_count : 0
  guest_name         = "ubuntu-node-${count.index + 1}"
  disk_store         = "automation-storage"
  ovf_source         = "/home/administrator/virtualbox-ova/noble-server-cloudimg-amd64.ova"
  memsize            = "2048"
  numvcpus           = "2"
  power              = "on"
  resource_pool_name = "/"

  network_interfaces { virtual_network = "VM Network" }

  guestinfo = {
    "userdata" = base64encode(<<-EOF
      #cloud-config
      user: admin
      password: automation@12
      chpasswd: { expire: False }
      ssh_pwauth: True
    EOF
    )
    "userdata.encoding" = "base64"
  }
}
