Deployment Guide

Overview: This engine provisions virtual infrastructure targets on a dedicated VMware ESXi cluster running on Cisco C220 M4 metal frameworks utilizing Terraform configurations.

Environment Prerequisite Vectors:

  • Cisco C220 M4 Bare-Metal Host Platform
  • HashiCorp Terraform Deployment Binary

Procedural Directives
  1. Initialize an instance of Windows Subsystem for Linux (WSL) running Ubuntu.
  2. Install the structural Terraform distribution framework within the shell execution terminal environment.
  3. Establish the local configuration asset matrix named terraform.tfvars to host secure connection points.
  4. Construct the environment parameters definition engine named variables.tf.
  5. Compose the structural build definitions profile sheet named main.tf.
