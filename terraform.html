Deployment Guide

Overview: This workspace provisions virtual machines on a VMware ESXi host running on Cisco C220 M4 hardware using Terraform. The operating system OVA deployment files are located locally in the virtualbox-ova directory inside the host Ubuntu environment.

Tools Used:

  • VMware ESXi Host (Cisco C220 M4)
  • Terraform
  • OS OVA Source Images
Workflow Steps
  1. Configure Windows Subsystem for Linux (WSL) running Ubuntu.
  2. Install Terraform inside the Ubuntu WSL instance.
  3. Create terraform.tfvars to securely store the ESXi host IP address and login credentials.
  4. Create variables.tf to define inputs and variable declarations for interactive prompt parameters.
  5. Create main.tf to define the target ESXi infrastructure configuration provider and guest resources.

Note: Default Terraform behaviors will replace resource tracks when modifying counts. The custom Bash script acts as a state wrapper to scale fleets incrementally without destroying active nodes.

  1. Create deploy.sh to inspect the current environment state, dynamically calculate the fleet delta, and cleanly scale up virtual machines without causing resource destruction.
Workspace Files
